What both versions do

Check before it opens

Every new site is looked at before it can do harm, then remembered, so repeat visits are quick.

You stay in charge

Rules are applied in a fixed order, so an AI guess can never override a choice you made.

Runs on your computer

The browser extension, the dashboard and the server all run on your own machine, with your own database.

What it can't do

  • It protects the browser it's installed in, not other browsers or apps.
  • The AI can be wrong, so you can always ask for a decision to be reviewed.
  • It slows a determined person down. It isn't a lock.

What stays private

  • Only a site's address is sent for checking, never the page you're on.
  • What you type is never collected, and cookie contents are never read.
  • Browsing history is deleted after 90 days.
